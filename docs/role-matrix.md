# Матрица ролей ЛР11

| Действие | Student (студент) | Teacher (преподаватель) | HeadOfDepartment (зав. кафедрой) | Гость |
|---|---|---|---|---|
| Просмотреть список заявок | да | да | да | нет → 401 |
| Создать заявку | да | нет → 403 | нет → 403 | нет → 401 |
| Назначить преподавателя | нет → 403 | нет → 403 | да | нет → 401 |
| Изменить статус назначенной себе заявки | нет → 403 | да | нет → 403 | нет → 401 |
| Изменить статус заявки другого исполнителя | нет → 403 | нет → 403 | нет → 403 | нет → 401 |

Назначение и смена статуса — отдельные операции: только `HeadOfDepartment`
может назначить пользователя с ролью `Teacher`, а менять статус может только
назначенный преподаватель. Сервер проверяет личность из HttpOnly cookie и
роль/назначение на каждом запросе; клиентские ограничения интерфейса не
заменяют эти проверки.

Учебные учётные записи в Development:

| Логин | Роль |
|---|---|
| `student.demo` | Student |
| `teacher.demo` | Teacher |
| `teacher.other` | Teacher |
| `head.demo` | HeadOfDepartment |
