## Цель

Отделить интерфейс от источника данных: список и форма вызывают
`getTickets` / `createTicket` из `api/tickets.js`, умеют ждать ответ
и показывают четыре взаимоисключающих состояния. Двойной клик не
создаёт две записи; `id` и `number` приходят из ответа.

## Что сделано

- `frontend/.env.example` с `VITE_API_BASE_URL=http://localhost:5000`,
  `.env` исключён из Git.
- `src/api/mockTickets.js` — задержка 500 мс, ответы 200/201/400/500,
  серверные `id`, `number`, `status: New`.
- `src/api/tickets.js` — единственная точка правды: `USE_MOCK`,
  `getTickets`, `createTicket`, класс `ApiError` с полями `status` и `kind`.
- `TicketList.vue` — одно поле `screen`: loading / empty / data / error.
- `TicketNew.vue` — `isSubmitting`, `:disabled`, `finally`,
  сообщения для 400 / 500 / нет связи, объект берётся из ответа.

## Проверки

| Проверка | Что делали | Факт |
|---|---|---|
| Успех | title = «Математический анализ», disciplineId = 2, description = «Пропустил экзамен по болезни, есть справка» | Строка добавилась, номер присвоен сервером, статус «Новая» |
| Пусто | mock вернул [] | Экран «Записей пока нет» |
| 400 | короткий title | «Заголовок: от 5 до 80 символов», строка не создана |
| 500 | `force500 = true` | «Сервер не смог обработать запрос» |
| Нет связи | `USE_MOCK = false`, backend не запущен | «Нет связи с сервером» |
| Двойной клик | два быстрых клика по «Создать» | Одна запись, кнопка disabled в момент запроса |

## Network

- Успешное создание: POST `http://localhost:5000/api/retake-requests`, статус 201.
- Отказ: POST, статус 400 / 500.
- Нет связи: неуспешная попытка к порту 5000, ветка `catch`.
- Для mock-прогонов HTTP-запроса нет — это ожидаемо, приложен скрин кода/консоли.

## Границы

- Backend на C# ещё не подключён, `USE_MOCK = true` по умолчанию.
