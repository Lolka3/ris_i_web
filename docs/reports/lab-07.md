## Цель
Создать каркас ASP.NET Core Web API на порту 5000 со Swagger, `/health` и `/info`. Заложить слои и DI.

## Что сделано
- Создан проект `backend/` (Web API, Controllers).
- Настроен порт `http://localhost:5000` в `launchSettings.json`.
- Swagger доступен в Development.
- Добавлены Minimal API эндпоинты:
  - `GET /health` — возвращает 200 и статус Healthy (проверка живости процесса).
  - `GET /info` — возвращает имя приложения и среду.
- Созданы папки `Controllers`, `Services`, `Models`, `Data` (добавлены файлы-заглушки, чтобы Git их видел).
- Создан `HealthService` и `InfoController`, сервис зарегистрирован через DI (внедряется в конструктор контроллера, без `new`).
