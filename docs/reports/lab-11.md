# ЛР11. Вход и права

## Что сделано

- Добавлены вход, проверка текущей сессии и выход через cookie-аутентификацию.
  Cookie HttpOnly, SameSite=Strict, с восьмичасовым сроком действия.
- Пароли пользователей хранятся в формате ASP.NET Identity `PasswordHasher`;
  учебные хеши создаются при запуске Development из локальных User Secrets.
- API требует аутентификацию для чтения заявок; студент создаёт, зав. кафедрой
  назначает преподавателя, преподаватель меняет статус только назначенной ему
  заявки. Ошибки доступа — 401 или 403.
- Удалена доверенная идентификация через `X-User-Id`; сервер получает id и роль
  из проверенной cookie-сессии.
- Фронтенд использует API вместо mock-данных, предоставляет `/login`, отправляет
  cookie с запросами и показывает описание обычной интерполяцией Vue.

## Учебные пользователи

| Логин | Пароль для локального учебного контура | Роль |
|---|---|---|
| `student.demo` | `StudentLab11!2026` | Student |
| `teacher.demo` | `TeacherLab11!2026` | Teacher |
| `teacher.other` | `OtherTeacherLab11!2026` | Teacher |
| `head.demo` | `HeadLab11!2026` | HeadOfDepartment |

Эти пароли предназначены только для локальной учебной базы и не должны
использоваться вне неё. Настройте их через User Secrets согласно README; в
таблице PostgreSQL сохраняются только полученные password hash.
